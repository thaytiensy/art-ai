# ART AI - HỌA SĨ NHÍ (DÀNH CHO HỌC SINH TIỂU HỌC LỚP 1 - 5)

Ứng dụng Web AI Giáo viên Mĩ thuật tương tác trực quan, miễn phí 100%, thiết kế chuyên biệt cho học sinh Tiểu học theo khung chương trình GDPT 2018.

---

## 🌟 CÁC TÍNH NĂNG NỔI BẬT DÀNH CHO BÉ

1. **🎨 Bảng Vẽ Họa Sĩ Nhí (Kids Canvas):**
   * Bút chì, cọ lông, sáp màu, cục tẩy, nhãn dán vui nhộn (⭐, ❤️, 🌸, 🌈, 🐱...).
   * Bảng 12 màu kẹo ngọt tươi sáng và kích cỡ nét cọ dễ chọn.
   * Nút **"Nhờ Cô Họa Mi Nhận Xét Tranh"** tự động chụp tranh từ canvas gửi cho cô giáo AI.

2. **👩‍🎨 Mắt Thần Nhận Xét Bài Vẽ (AI Art Critique):**
   * Nhận diện bài vẽ từ camera, tải ảnh từ máy tính hoặc từ bảng vẽ.
   * Phương pháp phản hồi tích cực (Sandwich Feedback): Khen ngợi 2 điểm sáng tạo -> 1 mẹo nhỏ họa sĩ -> Trao huy hiệu và điểm 10/10.
   * Tích hợp **Giọng nói Cô Họa Mi (TTS)** phát âm tiếng Việt ấm áp, vui tươi.

3. **🐾 Tập Vẽ Từng Bước (Step-by-Step Drawing):**
   * Bài học phân rã hình khối: Chú Mèo Con Lười, Ngôi Nhà Mơ Ước, Gấu Trúc, Hoa Hướng Dương, Xe Cứu Hỏa.
   * Chỉ dẫn theo từng bước trực quan kèm mẹo vẽ.

4. **✨ Xưởng Cảm Hứng & Bảo Tàng Tranh Thu Nhỏ:**
   * Tạo tranh mẫu phác thảo thiếu nhi từ bất kỳ ý tưởng nào qua Pollinations.ai (Hoàn toàn miễn phí, không cần key).
   * Khám phá các kiệt tác hội họa thế giới từ The Metropolitan Museum of Art (CC0).

## 🚀 HƯỚNG DẪN CHẠY VÀ TRIỂN KHAI

### Chạy cục bộ:
```bash
npm install
npm run dev
```
Truy cập: `http://localhost:3000`

### Triển khai miễn phí lên Vercel / Cloudflare Pages:
1. Đưa mã nguồn lên GitHub.
2. Kết nối repo với Vercel (chọn Framework Preset: Vite).
3. Bấm Deploy (100% miễn phí vĩnh viễn).
